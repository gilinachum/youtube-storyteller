# Hybrid Session Planning

## What Makes Hybrid Different

Hybrid is the hardest format. You're serving two audiences simultaneously:
- **In-room** — can see you, the screen, each other; have spatial presence
- **Remote** — see a camera feed + screen share; easily distracted; often forgotten

The #1 mistake: optimizing for the room and treating remote attendees as eavesdroppers.

## Planning Process

1. **Define format** — how many in-room vs. remote? Is one the "primary" audience?
2. **Tech setup** — camera, microphone, screen sharing, chat monitor
3. **Design for inclusion** — every interaction must work for BOTH audiences
4. **Assign roles** — speaker, chat moderator, room facilitator
5. **Create the session plan** with explicit hybrid checkpoints

## Session Structure

### Pre-Session (5 min before)
- Open the call early — let remote people trickle in
- Test audio/video from the remote perspective
- Display a "starting soon" slide with agenda + logistics

### Opening
- Acknowledge BOTH audiences explicitly: "Welcome to everyone in the room and online"
- Explain interaction rules upfront:
  - How to ask questions (hand raise vs. chat vs. both?)
  - Will you monitor chat? (Assign a chat monitor if possible)
  - When will you take Q&A?
- Quick tech check: "Can remote folks hear me clearly?"

### Body — Hybrid-Aware Design
- **Camera discipline** — face the camera, not just the room
- **Repeat room questions** into the mic before answering
- **Chat check-ins** every 10-15 min: "Anything in the chat?"
- **Polls** — use digital tools (Slido, Zoom polls) that both groups can access equally
- **Share visuals on screen** — don't point at a physical whiteboard remote can't see
- **If using a whiteboard/flipchart:** photograph and share immediately, or use a digital equivalent

### Closing
- Recap for both audiences
- Share resources link (same link, both groups)
- Thank remote attendees specifically

## Best Practices

### Audio (The #1 Failure Point)
- Use a **room microphone** (ceiling mic, Owl, or conference mic) — laptop mics don't work for rooms
- Remote people MUST hear clearly — this is non-negotiable
- Test from a remote device before the session
- Mute remote attendees by default to prevent echo
- Repeat in-room questions/comments for remote audience

### Video
- Position camera at **eye level** facing the speaker
- Use a wide-angle for room context + tight shot for speaker
- Ensure lighting is adequate — backlighting = silhouette for remote
- If using slides: share screen; don't point a camera at a projector screen

### Engagement Equity
- Use a **chat moderator** — someone dedicated to monitoring remote engagement
- Alternate between room and remote for Q&A
- Use "raise hand" features for remote, same priority as physical hands
- Digital-first for activities: use Miro, Jamboard, shared docs so both groups participate equally
- If doing breakout activities: put remote into Zoom breakout rooms, in-room into table groups

### Energy Management
- Remote fatigue sets in faster — break every 45 min for sessions > 1 hour
- In-room benefits from the speaker's physical presence — remote needs more variety
- Use more visuals, polls, and interaction for remote engagement
- Consider recording for remote attendees who zone out (share recording after)

## Common Mistakes

- ❌ Forgetting to share screen (presenting to room projector only)
- ❌ Speaking to the room with back to camera
- ❌ Not repeating room questions (remote hears the answer but not the question)
- ❌ Using physical-only activities (sticky notes on a wall that remote can't see)
- ❌ No dedicated chat moderator (questions go unanswered)
- ❌ Bad audio setup — echo, low volume, room noise
- ❌ Treating remote as second-class ("oh, we have people online too")
- ❌ Starting late because "we're waiting for room people" while remote waits silently
- ❌ Using body language/gestures that only the room can see

## Checklist

### 1 Week Before
- [ ] Room and Zoom/Chime/Teams booked
- [ ] Audio equipment identified and tested
- [ ] Camera position planned
- [ ] Chat moderator assigned
- [ ] Digital collaboration tool set up (Miro/Jamboard/shared doc)
- [ ] Agenda sent to BOTH audiences with join instructions
- [ ] Backup plan if internet fails (record + send later)

### Day Of — Tech Setup
- [ ] Test audio from a remote device (not your own laptop)
- [ ] Camera angle shows speaker face, not back/side
- [ ] Screen sharing works and is readable at screen-share resolution
- [ ] Chat moderator has access and knows the plan
- [ ] Backup charger for laptop
- [ ] Close all notifications (Do Not Disturb mode)

### During — Speaker Reminders
- [ ] Acknowledge remote audience in the first minute
- [ ] Face camera regularly (not just the room)
- [ ] Repeat room questions before answering
- [ ] Check chat every 10-15 min (or delegate)
- [ ] Use digital tools for polls/activities (not physical-only)

### After
- [ ] Share recording within 24h
- [ ] Send resources/follow-up to ALL attendees (both groups)
- [ ] Ask for feedback from remote AND room attendees
