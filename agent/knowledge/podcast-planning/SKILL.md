# Podcast Episode Planning

## Key Differences from YouTube Video

| Dimension | YouTube Video | Podcast |
|-----------|--------------|---------|
| Duration | 5-7 minutes (hard max) | 20-60 minutes (flexible) |
| Visuals | Essential | None (audio-first) |
| Scripting | Tight outline + script | Talking points (conversational) |
| Retention hook | Every 2 min | Every 8-10 min |
| Algorithm | Watch time % | Listen-through rate |
| SEO target | YouTube search | Apple/Spotify search + Google |
| Distribution | YouTube only | Spotify, Apple, Google, RSS |
| Output | Script + outline | Show notes + timestamps + transcript |

## Episode Formats

### Solo Episode ("מונולוג")
- Host speaks directly to audience
- Works best for: opinion pieces, tutorials, lessons learned
- Duration: 15-30 minutes
- Key challenge: Energy without a conversation partner

### Interview Episode ("ראיון")
- Host + one guest
- Works best for: practitioner insights, case studies, expert views
- Duration: 30-60 minutes
- Key challenge: Asking the right questions, active listening

### Co-host Episode ("דו-שיח")
- Two hosts in ongoing conversation
- Works best for: news/trends discussion, point-counterpoint, series regulars
- Duration: 30-50 minutes
- Key challenge: Prep alignment — avoid talking over each other

### Panel Episode ("פאנל")
- Host + 2-3 guests
- Works best for: multi-perspective topics, community discussions
- Duration: 45-60 minutes
- Key challenge: Giving equal airtime, managing flow

## Episode Structure

### Solo Episode (30 min example)

| Time | Segment | Purpose |
|------|---------|---------|
| 0:00-1:30 | Cold open / Teaser | Quote, insight, or provocative question |
| 1:30-3:00 | Intro + episode framing | Who this is for + what you'll get |
| 3:00-8:00 | Context / Background | Why this matters now |
| 8:00-20:00 | Main content | 2-3 key segments with examples |
| 20:00-27:00 | Practical takeaways | What to do with this information |
| 27:00-29:00 | Summary + resources | Recap + links |
| 29:00-30:00 | Outro + CTA | Subscribe, review, next episode |

### Interview Episode (45 min example)

| Time | Segment | Purpose |
|------|---------|---------|
| 0:00-1:30 | Teaser clip | Pull the best quote from the interview |
| 1:30-3:00 | Host intro + context | Why this guest, why now |
| 3:00-5:00 | Guest intro | Keep it short — guest introduces themselves |
| 5:00-35:00 | Interview | 4-6 main question areas |
| 35:00-42:00 | "Rapid fire" or deep-dive | Change of pace |
| 42:00-44:00 | Guest's takeaway / advice | Their single best message |
| 44:00-45:00 | Outro | Thank guest + listener CTA |

## Planning Process

1. **Define the episode brief:**
   - Episode title (working title)
   - Target audience (who is this for?)
   - Core question the episode answers
   - Format (solo/interview/co-host/panel)
   - Target duration

2. **Research:**
   - Use `deep_research` for topic background and current angles
   - Look for recent news, data points, or controversies to anchor the episode
   - For interviews: research the guest's background, recent work, public statements

3. **Build the episode outline:**
   - Segment titles + time estimates
   - 3-5 bullet talking points per segment
   - Transition lines between segments
   - Opening hook (teaser quote or provocative question)
   - Closing CTA

4. **For interview episodes — Guest Prep Pack:**
   - Guest bio (as read on air — 30-45 seconds)
   - Confirmed question list (share 3-5 questions in advance)
   - Surprise questions (2-3 held back for energy)
   - "Forbidden zones" check — topics to avoid
   - Technical setup instructions for the guest

5. **Show notes template:**
   - Episode title + one-sentence summary
   - Guest bio + links (if applicable)
   - Chapter timestamps
   - Key resources/links mentioned
   - Episode transcript link (if available)
   - CTA (subscribe/review/newsletter)

## Retention Techniques for Audio

Unlike YouTube, podcast listeners can't "see" — every retention tool is auditory:

- **Verbal signposting:** "Here's the key thing..." / "Wait — before we move on..." / "This is where it gets interesting..."
- **Cliffhangers between segments:** "I'll tell you exactly what happened in a minute, but first..."
- **Chapter bookmarks:** "We have four things to cover — let's start with the hardest one."
- **Guest teases:** "Before I bring in [guest], here's the question that sparked this whole conversation..."
- **Recap moments:** "So far we've covered X and Y — now let's get into Z"
- **Energy variation:** Alternate quiet insight moments with higher-energy examples or stories

## Podcast SEO Best Practices

### Title Formula
- Include the core keyword first: "Claude AI for Production: Lessons Learned with [Guest]"
- Episode number optional: "Ep. 42: ..." or just a title
- Israeli audiences: Hebrew title often works better for local discovery

### Description
- First 2-3 lines MUST contain core keywords (shown in truncated previews)
- 200-400 words for full description
- List chapters/timestamps
- Include guest name prominently
- End with subscribe CTA

### Tags / Categories
- Choose a consistent main category (Technology / Software Development)
- Use 3-5 relevant keywords per episode
- Platform-specific: Apple Podcasts focuses on description; Spotify on title + description

## Hebrew Podcast Specifics

- **Language flexibility:** Hebrew narration, English tech terms (same as YouTube rule)
- **Cultural context:** Israeli tech community is small and connected — name-drop of shared communities (8200, Mamram, well-known companies) creates instant credibility
- **Show notes:** Offer both Hebrew and English — improves international discovery
- **Title strategy:** Hebrew title for local search + English subtitle for international reach
  - Example: "לבנות Agent בפרודקשן — מה שלא מספרים לך | Building Production AI Agents"

## Output Format

### Episode Plan
Deliver as a structured document with:
- **Working title** (Hebrew + English variant)
- **Episode brief** (1 paragraph — what this episode covers and for whom)
- **Format + target duration**
- **Segment outline** with timestamps and talking points
- **Opening hook** (exact text suggestion)
- **Closing CTA** (exact text suggestion)

### Guest Prep Pack (for interview episodes)
- Guest bio (read-aloud version, 30-45 sec)
- Pre-send question list (3-5 questions)
- Surprise questions (2-3, hold back)
- Technical setup note for guest

### Show Notes Template
- Title + summary
- Guest links (if applicable)
- Chapter timestamps
- Resources mentioned
- Subscribe CTA

## Series Planning

When planning a podcast series:
- Define the **series arc** (what question does the series answer over 6-12 episodes?)
- **Episode 1:** Establish premise + introduce the host's POV
- **Mid-series:** Bring in guests and case studies
- **Final episode:** Synthesis + where to go next
- Maintain consistent segment names across episodes (helps listeners build habits)
- Consistent episode length (±5 min) — listeners plan their commutes around this

## Common Mistakes

- ❌ No intro/outro music — hard cuts feel unprofessional
- ❌ Over-scripting — podcasts sound best conversational, not read
- ❌ Interview with no research on guest — leads to generic questions
- ❌ Episodes > 60 min for a new show — earn long-form trust first
- ❌ Skipping show notes — you lose all the SEO value
- ❌ Asking yes/no questions in interviews — open-ended questions get better content
- ❌ Forgetting the CTA — always tell listeners what to do next
- ❌ Recording without a backup — always record a local track + cloud backup

## Checklist

### Pre-Production
- [ ] Episode brief written (title, audience, core question)
- [ ] Research done (deep_research if needed)
- [ ] Guest confirmed + bio collected (for interview)
- [ ] Questions written and sent to guest (3-5 advance + 2-3 surprise)
- [ ] Segment outline with timestamps
- [ ] Opening hook finalized

### Production Ready
- [ ] Recording setup tested (room, mic, levels)
- [ ] Guest briefed on tech setup
- [ ] Backup recording enabled
- [ ] Intro/outro music ready

### Post-Production
- [ ] Show notes written
- [ ] Chapter timestamps marked
- [ ] Transcript requested (use `start_transcription` tool if you have audio)
- [ ] Thumbnail / cover art for the episode
- [ ] Distribution scheduled (Spotify, Apple, RSS)
