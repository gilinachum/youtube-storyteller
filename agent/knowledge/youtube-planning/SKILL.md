# YouTube Video Planning

## Process

1. **Understand the goal** — topic, target audience, desired video length, channel context
2. **Research** — use `deep_research` to gather trends, competitor analysis, and content gaps
3. **Structure** — create a video outline with:
   - Hook (first 30 seconds)
   - Problem/question setup
   - Main content sections (3-5 key points)
   - Call to action
   - End screen strategy

## Output Format

Deliver the plan as a structured document with:
- **Title options** (3-5 variations, optimized for CTR)
- **Description** (SEO-optimized, with timestamps)
- **Tags** (15-20 relevant keywords)
- **Thumbnail concept** (text, imagery, colors)
- **Script outline** (section-by-section with talking points)

## Best Practices

- Hook must create curiosity or promise value in < 5 seconds
- Each section should have a mini-hook to retain viewers
- Include pattern interrupts every 2-3 minutes
- End with a clear CTA (subscribe, next video, comment)
- Title formula: [Number/How] + [Benefit] + [Timeframe/Qualifier]

## Hebrew Content Notes

- Titles can mix Hebrew + English (tech terms stay in English)
- Description: Hebrew first, English keywords in tags
- Consider Israeli audience preferences and cultural context
